## 🛠️ Troubleshooting Common Issues

**Problem: SmartScreen blocks the file**
Fix: Right-click the downloaded file, select Properties, check the "Unblock" box, and click OK. Or click "More info" on the SmartScreen popup and choose "Run anyway."

**Problem: Scan finds no devices**
Fix: Make sure your computer is connected to the network and the network is active. Check if your firewall is blocking the tool. Temporarily disable Windows Defender Firewall, run the scan, then re-enable it. If it works, add the tool to the firewall's allowed list.

**Problem: Duplicates found but no fix works**
Fix: Power-cycle every device on the network. Turn off the router, turn off all computers, turn off all IoT devices. Wait 60 seconds. Turn on the router first, wait 2 minutes, then turn on each device one by one. Rescan.

**Problem: Tool won't launch at all**
Fix: Right-click the file and select "Run as Administrator." If that doesn't work, download the file again in case the previous download was incomplete. Clear your browser cache and retry.

**Problem: Scan says "Access Denied"**
Fix: You need to run the tool with administrative rights. Close it, then right-click and choose "Run as Administrator." This gives it permission to read network information.

**Problem: Results seem incomplete**
Fix: In Settings, increase the scan range. For example, if your router uses 192.168.0.1, scan the full range: 192.168.0.2 to 192.168.0.254. This covers all possible IP assignments.

**Problem: The tool crashes on startup**
Fix: Update your Windows operating system to the latest version. Then restart your computer and try again. If it still crashes, check if another security tool like antivirus is quarantining it. Add an exception.

## 📋 Frequently Asked Questions

**Is this tool safe to use?**
Yes. It only reads network information. It does not modify your router, change settings, install background services, or send data anywhere. It runs locally on your machine.

**What does "duplicate IP" actually mean?**
Think of IP addresses like house addresses on your street. Two houses cannot share the same address, or mail goes to the wrong house. On a network, devices use IP addresses to send data to each other. If two devices have the same IP, they confuse each other, causing dropped connections and errors.

**How often should I run a scan?**
Once a week is a good practice for home networks. For offices, run it daily. You can also set up automatic rescans in settings.

**Can I scan multiple networks?**
Yes. If your computer is connected to a VPN or multiple adapters, you can switch between them in Settings. The tool detects all active network interfaces.

**Will this fix my internet speed?**
Not directly. It fixes IP conflicts, which cause total disconnections and errors. If your speed is slow but never disconnects, a conflict is unlikely to be the cause.
